# 🎓 Student Performance Analyzer

A **C-based application** designed to manage and evaluate student academic performance. The system allows users to add, view, and analyze student records while automatically calculating marks, percentages, grades, and pass/fail status.

---

## 📌 Features

* ➕ Add new student records
* 📋 View all student records
* 🔍 Analyze individual student performance
* 📊 Calculate total marks
* 📈 Calculate percentage
* 🎓 Automatically assign grades
* ✅ Determine Pass/Fail status
* 💪 Identify the strongest subject
* ⚠️ Identify the weakest subject
* 🖥️ User-friendly menu-driven interface

## 📊 Performance Analysis

The application analyzes a student's academic performance by calculating:

* **Total Marks**
* **Percentage**
* **Grade**
* **Pass/Fail Status**
* **Strongest Subject**
* **Weakest Subject**

---

## 🎓 Grade System

| Percentage | Grade |
| ---------- | ----- |
| 90% - 100% | A     |
| 80% - 89%  | B     |
| 70% - 79%  | C     |
| 60% - 69%  | D     |
| 50% - 59%  | E     |
| Below 50%  | F     |

A student must score at least **40 marks in each subject** to achieve a **Pass** status.
